# English Flow

A friendly English-learning platform built with Next.js, React and TypeScript.

## First version
- Responsive learning dashboard
- Daily learning checklist with progress
- Grammar quick-check quiz with feedback
- Learning areas for grammar, vocabulary, reading and exam practice

## Run locally
1. Install Node.js (LTS) from https://nodejs.org
2. In this project folder, run `npm install`
3. Run `npm run dev`
4. Open http://localhost:3000

This is the first frontend prototype. Lesson content, user accounts, saved progress, audio, and exam question banks can be added in later stages. Use original or appropriately licensed exam practice content; do not republish copyrighted full exam papers.
