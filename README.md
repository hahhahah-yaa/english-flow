# English Flow

A daily English-learning workspace built with Next.js, React and TypeScript. The learning path is designed for a B1 learner progressing toward B2 and eventually C1.

## Current learning features
- Daily intensive routine across grammar, vocabulary, reading, listening, writing and speaking
- Rotating daily themes and a small rotating set of reading passages and vocabulary
- Grammar practice with explanations
- Vocabulary cards with definitions, collocations, examples and sentence prompts
- Reading comprehension and inference questions
- Browser text-to-speech for listening scripts and vocabulary examples (voice availability depends on the user's browser/device)
- Writing task with target word count and a basic automated self-review checklist
- Speaking prompts and reflection notes
- Daily progress and local browser storage for progress, known words and drafts
- A basic list of grammar questions answered incorrectly

## Important limitations
- Daily materials rotate from a small, prewritten content set; they are not generated or refreshed from the internet automatically each day.
- Progress is stored in the current browser only. There is no account, cloud sync or cross-device history.
- Browser speech synthesis reads the text aloud; it is not a recorded listening library with different speakers, accents or comprehension audio.
- Writing review is a limited checklist, not an AI assessment of grammar, coherence or C1-level quality.
- The current question bank is a prototype and is not yet a complete B1–C1 curriculum.

## Next development phase (keep on roadmap)
1. Expand the structured question bank by topic and CEFR level (B1, B2, C1), with varied question types and explanations.
2. Add a real audio listening library with varied speakers/accents, transcripts, comprehension questions and replay controls.
3. Build a spaced-repetition mistake review system: store errors, schedule review, track repeated errors and revisit them until mastered.
4. Improve B2/C1 writing feedback with task response, organisation, vocabulary range, grammar accuracy and actionable corrections.
5. Add progress-based adaptive sequencing, weekly review and a reliable streak/calendar.
6. Add user accounts and cloud persistence so learning materials and progress sync across devices.

## Run locally
1. Install Node.js (LTS) from https://nodejs.org
2. Run `npm install`
3. Run `npm run dev`
4. Open http://localhost:3000
